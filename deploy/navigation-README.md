# 全站共享导航

2026-09-21 已上线：主页、博客（含文章页）、竞赛、算法板子、学习资料共用同一顶部导航。

- 固定项目和顺序：主页 / 博客 / 竞赛 / 板子 / 资料。
- `public/index.html` 的 `#site-navigation` 是导航结构的唯一来源。
- Node 构建器通过 `scripts/site-header.mjs` 读取共享结构，仅更改 `aria-current="page"`。
- Python 资料构建器读取同一首页导航，替换 `{{SITE_HEADER}}`。
- `public/navigation.css` 统一品牌、字体、选中态、布局、主题按钮和底部分隔线；置于页面专属样式之后加载。
- 导航最大宽度 1080px，高度 104px；700px 以下高度 88px；320px 屏幕下五个入口仍直接可见。
- `scrollbar-gutter: stable` 避免不同页面滚动条宽度导致导航水平跳动。
- 页面共用全站画布色；板子页移除独立色板，沿用全站日夜主题变量，保留阅读布局。
